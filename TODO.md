# VELOCITY MOTORS — Outcome Checklist

## 1. Cinematic red Porsche 918 opening experience
- [x] The first thing visitors see is a cinematic, full-screen opening featuring a glossy red Porsche 918 Spyder.
- [ ] Start from a completely dark screen. Reveal the car with cinematic red light, a dramatic headlight close-up, then front, side profile, wheels and rear design; use smooth camera-style motion, cinematic transitions, subtle floor reflections, and realistic showroom lighting and shadows.
- [x] Add an elegant engine-start sound effect with mute/unmute control and a premium loading animation before the homepage appears. Keep the intro skippable and provide reduced-motion handling.
- [x] Hero text is “PORSCHE 918 SPYDER” and “Born to Perform. Designed to Inspire.” Buttons are “EXPLORE THE CAR” and “VIEW COLLECTION”. The opening should feel like a luxury automotive commercial, not a standard website intro, and create a strong first 5–8 seconds.

## 2. Featured collection and model-specific details
- [x] Show Porsche 918 Spyder – Red; Porsche 911 GT3 RS; Ferrari SF90 Stradale; Lamborghini Aventador SVJ; McLaren 720S; Mercedes-AMG GT; BMW M4 Competition; and Audi R8.
- [x] Each vehicle card has an accurate, legally usable car image; brand and model; horsepower; top speed; 0–100 km/h acceleration; engine information; and an Explore Details action.
- [x] Keep specifications accurate to an identified model year/trim and market. Preserve source units and identify conversions, estimates, approximate figures, or market-dependent information clearly.
- [x] Provide a visually impressive collection, a detailed vehicle information page for each model, and search/filter controls for brand, price and category. Price tiers must be described as indicative, not fabricated asking prices or confirmed inventory.

## 3. Dedicated Porsche 918 Spyder showcase and gallery
- [x] Provide a dedicated 918 Spyder experience with sections for exterior design, interior design, engine and hybrid performance, performance specifications, gallery, and technical details.
- [x] Use large vehicle imagery, cinematic scrolling transitions and elegant specification animations.
- [x] Provide fullscreen image viewing in the gallery and a route from the hero and collection into the 918 showcase.

## 4. Showroom interactions and enquiry flows
- [x] Implement detailed car pages; persistent favourite/wishlist cars; enquiry form; test-drive booking request; and a WhatsApp enquiry integration.
- [x] Make all buttons, navigation links, search/filter controls and image viewing interactions functional.
- [x] Enquiry fields include name, email, phone number, interested car and message. Provide validation and an accurate success/error state.
- [x] Securely forward enquiries to Supabase when credentials and the expected table are configured; never expose service credentials in browser code. If not configured, clearly identify local demonstration behavior rather than implying cloud storage.

## 5. Luxury virtual showroom
- [x] Include a dark luxury showroom background with dramatic spotlighting and large vehicle images.
- [x] Let visitors interactively select a car and experience a premium showroom atmosphere.

## 6. Brand story and visual identity
- [x] Present VELOCITY MOTORS as an exclusive destination for luxury and performance vehicles, using premium photography, elegant layouts and a strong brand identity.
- [x] Use deep black, graphite grey, metallic silver, Porsche-inspired red accents and white typography; keep the style minimalist, cinematic and premium with smooth scrolling, glass-like navigation and elegant hover animation.
- [x] Avoid generic templates, excessive gradients, cartoonish graphics and unnecessary UI.

## 7. Navigation and responsive mobile experience
- [x] Provide transparent premium navigation for Home, Our Collection, Supercars, Luxury Cars, About Us and Contact, plus search and a premium enquiry button.
- [x] Support desktop, laptop, tablet and mobile. The mobile navigation works, and the cinematic 918 opening remains compelling while optimizing animation and image weight/performance.
- [x] Provide smooth page/section transitions and accessible controls for reduced-motion and keyboard use.

## 8. Functional build, imagery and delivery
- [x] Deliver a complete functional responsive website, not just a static design; use Next.js, React, TypeScript, Tailwind CSS, Framer Motion; Three.js/React Three Fiber is optional; prepare Supabase for enquiry storage and keep the project Vercel-compatible.
- [x] Use high-quality, legally usable automotive photographs and retain the corresponding source/license credit. Do not leave placeholder boxes or broken image links.
- [ ] Keep the red Porsche 918 Spyder central to the visual identity. Verify desktop/mobile layout and the production build before delivery.
